# Bundled fonts

Sora, Inter and JetBrains Mono, Latin and Latin Ext woff2 subsets from Google Fonts.

- Sora: display face, weights 400 to 800
- Inter: UI face, weights 400 to 700
- JetBrains Mono: timecodes and diagnostics, weights 400 to 700

All three are licensed under the SIL Open Font License 1.1. The license text is in `OFL.txt`.
The files are unmodified subsets served by Google Fonts.

Sources:

- https://fonts.google.com/specimen/Sora
- https://fonts.google.com/specimen/Inter
- https://fonts.google.com/specimen/JetBrains+Mono
