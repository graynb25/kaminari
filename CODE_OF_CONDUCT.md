# Contributor Covenant Code of Conduct

Our pledge is simple. Kaminari is a small open source project. Everyone should feel welcome here. Be kind, be useful, and assume good intent.

Examples of actions that create a welcoming space:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Accepting constructive criticism with grace
- Focusing on what is best for the community
- Showing empathy towards other members

Unacceptable behavior includes harassment, personal attacks, trolling, publishing private information, and other conduct that would reasonably be considered inappropriate in a professional setting.

Project maintainers are responsible for clarifying standards and for enforcement. Report issues to the maintainer through the contact in the README. Reports are reviewed privately. Enforcement may include a warning, a temporary ban, or a permanent ban depending on severity.

This code of conduct is adapted from the Contributor Covenant, version 2.1, hosted at https://www.contributor-covenant.org/version/2/1/code_of_conduct.html.
